# متابَع

منصة تعرض منشورات صفحات فيسبوك التي تختارها فقط، مع تطبيق أندرويد (APK) يُبنى تلقائياً.

## محتوى المستودع
- `docs/` — المنصة نفسها، تُنشر على GitHub Pages.
- `docs/pages.json` — قائمة الصفحات. عدّلها من GitHub مباشرة وتتحدث المنصة والتطبيق عند كل المستخدمين.
- `android/` — تطبيق أندرويد يفتح المنصة.
- `.github/workflows/build-apk.yml` — يبني ملف APK على خوادم GitHub وينشره في صفحة Releases.

## تعديل الصفحات
افتح `docs/pages.json` في GitHub، اضغط على أيقونة القلم، عدّل القائمة ثم اضغط Commit changes.
كل عنصر بهذا الشكل:

```json
{"name": "اسم الصفحة", "url": "https://www.facebook.com/اسم-الصفحة", "type": "page"}
```

استعمل `"type": "group"` للمجموعات.
