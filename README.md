# متابَع

تطبيق أندرويد يفتح فيسبوك بحسابك مباشرة على خلاصة **الصفحات التي تتابعها فقط**، مرتبة من الأحدث، دون منشورات مقترحة.
في أسفل التطبيق: الصفحات، المجموعات، المفضلة، وقائمة (⋯) فيها التحديث وتبديل عرض الهاتف/الحاسوب وتسجيل الخروج.

- `android/` — كود التطبيق.
- `.github/workflows/build-apk.yml` — يبني ملف APK تلقائياً وينشره في صفحة Releases عند كل تعديل.
- `docs/` — النسخة القديمة (عرض صفحات مختارة عبر أداة فيسبوك).
